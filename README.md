# Draft to DXF

PDF・JPEG・PNG・TIFFの図面を線・円・円弧に変換し、修正してPDF・DXFへ出力するブラウザ版です。

## ブラウザで使う

**[Draft to DXF を開く](https://meganezaru1096-hue.github.io/draft-to-dxf/?v=20261103)**

URLを開くだけで使用できます。ZIPのダウンロード・展開・追加インストールは不要です。初回は処理エンジンの読み込みに時間がかかります。
図面はサーバーへ送信せず、ブラウザ内で処理します。完成したPDF・DXFは保存ボタンから保存できます。
設定はこの公開URLを開いた同じブラウザに保存されます。ZIP版や別PCからの設定移行は設定ファイルを使ってください。

## 起動

1. 上記のZIPをダウンロードし、右クリックの「すべて展開」で解凍します。
2. 展開先の「図面変換ソフト」フォルダを開きます。
3. **「Draft to DXF.html」をMicrosoft Edgeで開きます。**
4. 準備が完了したら図面を開いて変換します。

ZIPの中を直接開かず、必ず展開してください。「アプリ本体」「ライセンス」は削除・移動せず、フォルダごと保管します。Python等の追加インストールは不要です。

ZIP版は上記のリンク、またはリリース内の `Draft_to_DXF_2026-11-03.zip` を使用してください。ブラウザで使う場合はダウンロード不要です。

## 今回の改善

- 起動準備中にロード演出と実際の準備段階を表示。
- 直線の許容ずれの標準値を10pxへ変更（保存済み設定は維持）。
- 削除の標準ショートカットはD。既存の個別キー設定や競合は保護。
- 直線統合で円弧を選んだ場合、直線化してから1本へ統合。失敗時は元の円弧を保持し、成功時はUndo1回で復元。
- 測定線は測定後も表示し、別の操作で消去。測定値は実寸合わせに引き続き利用可能。
- 文字・画像・塗りが併存するPDFでも、可能な直線・円弧を直接保持して残りだけ追加抽出。矩形クリッピングも直接処理。
- 複雑な切り抜きや線を覆う描画など、直接取込で見た目を失う場合は画像処理を維持。

## 主な機能

- 線・円・円弧の抽出、選択、移動、削除、描き足し
- 直線や円・円弧の統合、水平・垂直、角の作成、延長、分割、区間削除
- 下絵と線の重ね合わせ、範囲再変換、線の点検、元に戻す
- 距離測定、既知の直線長または2点間距離による実寸設定
- PDF・DXF出力、編集データ・複数ページ作業の保存
- ショートカットや許容値、ノイズ除去、PDF読込設定の自動保存

PDF DPIは300・400・600・1200から選べます。画像から処理する場合は1ページ4000万画素までです。7136×5056のTIFFも縮小せず読み込めます。

設定は同じ起動ファイル・同じブラウザで引き継ぎます。別PCへは設定画面のファイル保存・読み込みを使用してください。ブラウザの保存データを消去すると、保存した設定も消えます。

## 保存時の注意

- 図面の自動変換結果と実寸は、元図面や既知寸法で確認してください。
- **別の「作業」ファイルを開く前に、現在の作業を保存してください。** 未保存の内容を自動で退避する機能はありません。
- 複数ページで作業ページを切り替えた後、「ページ」欄の番号が追従しない場合があります。**再変換の前に対象のページ番号を確認し、合わせ直してください。**
- **用紙換算DPIを空欄にしたまま作業を保存しないでください。** 1～9600の有効な数値を入力してください。
- 自動バックアップは現在の図面の最新1件が対象です。元の入力ファイルや全ページの保管には「作業を保存」を併用してください。

## 同梱物

配布用ソフト・使い方・第三者ライブラリのライセンス表示を含みます。サンプル図面、個人の設定ファイル、保存した作業データ、Android版の署名鍵は含みません。

第三者コンポーネントのライセンスとソースの参照先は、ZIP内の「ライセンス」フォルダを確認してください。
