クリックで選択 / Ctrl＋クリックで追加・解除 / ドラッグで枠内の線を選択 / ホイールで拡大 / Shift＋ドラッグで移動。角を作る場合は、それぞれの線の残したい側をクリックして2本選択。元の角度のまま交点へ延長・短縮します。

編集後を表示

DXFは実寸設定時には指定した縮尺、未設定時は用紙上のmmで出力。PDFはDPIに基づく用紙サイズを維持します。画像は元画像のdpiに合わせてください。PDFは余白追加なし・ベクター出力。

編集データは線・下絵・解像度を保存。元PDFは含みません。元に戻す履歴は最大30操作で、再読込み時は引き継ぎません。
